# Pool Table Management System 🎱

<p align="center">
  <img src="Images/pool-table.png" alt="Pool Table Management System" width="800">
</p>

A simple Windows Forms application for managing pool tables, tracking playing time, and calculating total fees.

## Features

- 🎱 Manage multiple pool tables.
- ▶️ Start and pause table sessions.
- ⏱️ Track playing time.
- 💰 Calculate total fees based on the hourly rate.
- 🛠️ Set a table to Maintenance mode.
- 🔄 Make a table Available again.
- 📢 Raise an event when a session ends and return:
  - Consumed time
  - Total seconds
  - Hourly rate
  - Total fees

## Table Status

Each table status is represented by a different color for easy identification:

- 🟢 **Available** — Table is available for use.
- 🔵 **Playing** — A session is currently active.
- 🟡 **Paused** — The current session is temporarily paused.
- ⚫ **Maintenance** — Table is unavailable due to maintenance.

## Technologies

- C#
- Windows Forms
- .NET
- User Controls
- Events & EventArgs
